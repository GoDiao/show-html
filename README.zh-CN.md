# show-html

一个跨平台 agent 技能包，教 AI agent 生成自包含、零依赖的 HTML 页面——用于代码审查、演示文稿、状态报告、交互式编辑器、数据可视化等场景。

## 灵感来源

本项目灵感来自 [ThariqS/html-effectiveness](https://github.com/ThariqS/html-effectiveness)——一个展示"HTML 作为 agent 输出格式的惊人效果"的独立 HTML 示例库。本技能包 `assets/` 中的前 20 个示例文件来源于该仓库（Apache 2.0 许可）。示例 21–24 为原创新增内容。

## 包含内容

- **SKILL.md** — 技能定义，包含设计系统、用例索引和生成工作流
- **25 个 HTML 文件** — 1 个画廊索引页 + 24 个自包含参考页面
- **4 套可切换主题** — 画廊、暗黑展览、终端、禅意（仅改变颜色，保留每个页面独特的布局与字体）

### 设计亮点

每个文件都有**独特的视觉个性**：

- **编辑 Lookbook**（05）— Cormorant Garamond，色卡式色板
- **瑞士国际主义风格**（06）— Space Grotesk，点阵网格，零圆角
- **创意工作室暗黑模式**（07）— Syne，毛玻璃效果，浮动光球
- **产品设计展示**（08）— Plus Jakarta Sans，青色点缀，设备框架
- **蓝图/工程制图**（13）— 深蓝网格覆盖，悬停发光节点
- **学术教科书**（15）— Georgia 衬线体，页边线，阅读进度条
- **Notion 级项目管理**（16）— 里程碑时间线，工作量标签，进度追踪
- **深色仪表盘**（21）— DM Serif Display，迷你折线图，甜甜圈图表
- **Mermaid 架构图**（23）— 声明式流程图和序列图

### 主题系统

画廊索引页（`index.html`）通过浮动切换器提供 4 套主题：

| 主题 | 描述 |
|------|------|
| **画廊**（默认） | 温暖编辑风 — Playfair Display，象牙白背景 |
| **暗黑展览** | 深炭灰底色，霓虹点缀，聚光灯卡片 |
| **终端** | 黑底绿字极客风，Space Mono，发光效果 |
| **禅意** | 极致留白，若隐若现的点缀，无阴影 |

所有 24 个子页面通过 `localStorage` 继承所选主题——仅改变颜色，布局和字体保持不变。

## 安装

1. 将 `show-html/` 目录放在 agent 的技能路径下
2. 或安装 `show-html.skill` 包

## 使用方式

- 显式调用：`/show-html` 或 `/show-html:code-review` 等
- 根据任务上下文自动触发（如"审查这个 PR"、"写个周报"）
- Agent 将示例作为参考库阅读，然后从零生成风格类似的 HTML

## 打开画廊

直接在浏览器中打开 `show-html/assets/index.html`——无需构建步骤，无需服务器。
